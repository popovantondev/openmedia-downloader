# Форматы, режимы передачи и трансляции

![Главное окно программы на русском языке](../assets/screenshots/ru/main-window.png)

## Загрузка файлов

| Выбор | Результат | Примечания |
| --- | --- | --- |
| Видео | MP4 | Видео и звук могут передаваться отдельными дорожками; при необходимости они объединяются. Источник должен предоставлять совместимые форматы. |
| AAC | M4A | Готовая дорожка AAC копируется без перекодирования. Если подходящей AAC-дорожки нет, программа не выдаёт другой формат за AAC. |
| MP3 | MP3 | Звук преобразуется с помощью FFmpeg. Выбранный битрейт MP3 — параметр кодирования, а не обещание качества исходника. |

Доступное качество зависит от видео. Для AAC нельзя выбрать разрешение видео. Режимы **Авто**, **Напрямую** и **Фрагментами** используют разные варианты источника. Прямая передача может не сработать, если источник не предлагает подходящий цельный поток. Загрузка фрагментами зависит от доступных у источника HTTP-, HLS- или DASH-форматов. Не каждое видео поддерживает все варианты.

Показанный размер может быть приблизительным (`≈`). Если размер неизвестен, программа не подставляет выдуманный ноль. Для видео и звука оценки могут показываться отдельно.

## Запись текущих трансляций

Программа может распознавать поддерживаемые запланированные, текущие и завершённые трансляции. Запланированная трансляция не занимает слот загрузки. Для текущей трансляции выберите **Записывать с текущего момента**. Вариант **С начала** предлагается только если источник явно сообщает о поддержке; функция экспериментальная и всё равно может завершиться ошибкой источника.

Во время записи программа показывает прошедшее время, объём данных и скорость. Пока трансляция идёт, конечный размер и процент выполнения неизвестны. Нажмите **Остановить и сохранить**, чтобы корректно завершить запись. Успех отображается только после завершения процесса, сохранения файла и проверки медиа. При ошибке финализации может быть указан временный путь восстановления; прочитайте сообщение, прежде чем что-либо удалять.

AAC/M4A копируется только если трансляция содержит AAC-дорожку. Преобразование в MP3 начинается после остановки. Программа не пытается принудительно обрабатывать нераспознанные или защищённые трансляции.
