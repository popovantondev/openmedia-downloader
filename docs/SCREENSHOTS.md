# Datenschutzfreundliche Screenshots

![Beispiel: App-Fenster im deutschen Sprachmodus](../assets/screenshots/de/main-window.png)

Öffentliche Screenshots müssen eine künstliche, getrennte Vorführumgebung zeigen:

1. Verwenden Sie einen Test-Build oder eine leere App-Einstellung und eine synthetische Warteschlange. Melden Sie sich bei keinem Medienkonto an.
2. Nutzen Sie erfundene Titel wie `Synthetic Demo Clip`, `Playlist Sample 01` und neutrale Beispiel-Domains. Keine echten Video-Links, Verlaufstitel, Zielordner oder Konto-Avatare.
3. Stellen Sie sicher, dass keine Cookie-, Authentifizierungs-, Überschreibungs- oder privaten Fehlerdialoge geöffnet sind.
4. Prüfen Sie vor dem Speichern Bildinhalt und Dateimetadaten. Entfernen Sie EXIF-, GPS-, Autor-, Gerätenamen- und Kommentar-Metadaten; kontrollieren Sie auch Dateinamen.
5. Speichern Sie nur bereinigte PNG-Dateien. Veröffentlichen Sie keine Bildschirmaufnahme des echten Desktops oder Finder-Fensters.

Jede Anleitung muss Screenshots in der Sprache der Anleitung zeigen. Stellen
Sie die App vor der Aufnahme wirklich auf Deutsch, Englisch oder Russisch um;
übermalen oder ersetzen Sie keine UI-Texte. Geplante Ablage: `assets/screenshots/de/`,
`assets/screenshots/en/` und `assets/screenshots/ru/`.

Wenn sich ein Screenshot nicht sicher anonymisieren lässt, erstellen Sie die Szene neu. Vorhandene Projekt-Icons sind keine UI-Screenshots und dürfen nicht als Beleg für eine ausgeführte App dargestellt werden.
