OpenMedia Downloader

Проверяет поддерживаемые медиассылки и позволяет выбрать разрешённую загрузку или запись трансляции.

Только исходники · 5.5.0 macOS 15+ · Apple Silicon
Руководство Исходный код Swift · Python

Перед запускомТолько исходники: распространение готового приложения пока не согласовано по сторонним компонентам. Сохраняйте только материалы, на которые у вас есть право.

Готового установочного пакета нет. Инструкции описывают настройку из исходников.

Что внутри

Установка, функции, передача данных и проверка.

Проверка из исходников

Приложение на Swift с бэкендом на Python (yt-dlp, FFmpeg, Deno). Готового приложения пока нет; шаги — по руководству «Архитектура и сборка».

Нужно: Mac с Apple silicon, macOS 15 или новее, Swift 6 (Xcode или Command Line Tools)
swift build
swift test
Собираются и проверяются только компоненты Swift – без полного приложения и без настоящих загрузок

Подключение

Приложение работает локально на вашем Mac и загружает материалы напрямую с соответствующей платформы, например YouTube или Vimeo. Собственного облачного сервиса нет. Cookies необязательны; публичные материалы можно попробовать и без них.
