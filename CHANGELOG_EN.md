# Changelog

Product changes. Entries distinguish implemented code from completed verification.

## 5.5.0 — in development

- Progressive link and playlist inspection, with titles and metadata arriving incrementally.
- Playlist selection starts with no items selected and remains separate from download jobs.
- Added states for scheduled, ongoing, and completed streams, plus recording controls.
- Supported YouTube and Vimeo embed links can be inspected.
- Language, appearance, queue, and authentication features continue to evolve.
- New packaging and public documentation are being prepared.

**Status:** This is not an approved binary release. Full package and component-rights review remains open; see [rights and release status](docs/RIGHTS_EN.md). Integrated network, live-stream, visual, and second-Mac acceptance must be reported separately.

## 4.0.4

- App icon added to the window header and link editor layout improved.
- Existing 4.x app and installations remain separate from the 5.5.0 development line.

Earlier 4.x release notes and test reports are not part of this 5.5.0 source package. Earlier test results do not prove 5.5.0 readiness.
